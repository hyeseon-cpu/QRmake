# QR 코드 생성기

링크를 입력하면 QR 코드를 만들어 주는 웹페이지예요. 여러 링크를 한 번에 넣어서 QR 코드를 여러 개 만들 수 있어요.

**사이트:** https://hyeseon-cpu.github.io/QRmake/

![QR 코드 생성기 화면](docs/screenshot.png)

## 기능

- 링크를 한 줄에 하나씩 입력하면 QR 코드를 한 번에 생성
- 링크 앞에 `별칭: `을 붙이면 카드에 별칭 표시 (예: `메인 페이지: https://example.com`)
- 별칭을 영어로 하면 다운로드 이름에 반영이 돼요. 다수의 QR을 한꺼번에 다운도르할 때 유용해요.
- 크기 선택 (200 / 300 / 400 / 500px)
- QR 코드마다 QR 색상, 배경 색상 변경
- 가운데 로고 넣기: 로고 이미지를 올리면 모든 QR 코드 가운데에 들어가요 (크기: 작게 / 보통 / 크게). 로고가 있으면 오류 복원 수준을 최대(H)로 올려서 로고에 가려져도 잘 읽혀요.
- 배경 투명: 카드마다 "배경 투명"을 켜면 배경 없이 QR 코드만 있는 PNG로 저장돼요.
- QR 코드를 하나씩 또는 전체를 PNG로 다운로드

## 사용 방법

1. 사이트에 들어가서 입력창에 링크를 붙여 넣어요.
2. 크기를 고르고 **QR 코드 생성** 버튼을 눌러요.
3. 필요하면 색상을 바꾸고 **PNG 다운로드**나 **전체 다운로드**를 눌러요.

## 구조

`index.html` 파일 하나로 되어 있어요. QR 생성 라이브러리([qrcode](https://github.com/soldair/node-qrcode))가 파일 안에 들어 있어서 따로 설치할 게 없고, 인터넷 없이 파일을 브라우저로 열어도 동작해요.

## 배포

GitHub Pages로 `main` 브랜치의 루트를 배포해요. `main`에 push하면 1~2분 뒤 사이트에 반영돼요.
